# Get It (interactive demo)

A clickable prototype of a hospitality booking platform. One static page, no database, no build step.
Sample data is saved in the visitor's own browser, and the "Reset demo" link restores it.

## Put it online with Vercel
1. Create a GitHub repository and upload `index.html` and this README.
2. In Vercel choose Add New, Project, pick the repository, and click Deploy. No settings needed.

Or skip GitHub: install the Vercel CLI and run `vercel` inside this folder.
